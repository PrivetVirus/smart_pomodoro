# Smart Pomodoro 🍅

Умный таймер для работы по технике Pomodoro, написанный на **Python**. 

**Описание:**
- Помогает сфокусироваться на задачах и управлять временем (тайм-менеджмент).
- Сохраняет статистику сессий и прогресс в локальный файл `data.json`.
- Имеет графический или консольный интерфейс (в зависимости от сборки `main.py`).
