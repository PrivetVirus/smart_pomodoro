# 🍅 Smart Pomodoro Timer

**Smart Pomodoro** — это "умное" и стильное приложение-таймер по методу Помодоро, созданное для повышения концентрации и продуктивности. Проект сочетает в себе бэкенд на Python и красивый интерфейс на веб-технологиях.

---

## 🚀 Особенности
- **⏳ Классический Pomodoro**: 25 минут работы, 5 минут отдыха (настраивается!).
- **📊 Статистика**: Учёт всех рабочих сессий с сохранением результатов в локальный JSON файл (`data.json`).
- **🎨 Красивый UI**: Современный, плавный веб-интерфейс с анимациями.
- **🎵 Уведомления**: Звуковые оповещения о завершении таймера.
- **🔄 Кроссплатформенность**: Работает везде, где есть браузер и Python.

## 🛠 Технологии
- **Frontend**: HTML5, CSS3, Vanilla JavaScript.
- **Backend**: Python (для обработки и сохранения статистики).
- **Хранение данных**: JSON.

## 📥 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/PrivetVirus/smart_pomodoro.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd smart_pomodoro
   ```
3. Запустите главный файл (если используется локальный сервер Python):
   ```bash
   python main.py
   ```
4. Откройте интерфейс в браузере.

## 🧠 Как работает метод Помодоро?
1. Выберите задачу для выполнения.
2. Запустите таймер на 25 минут.
3. Работайте, не отвлекаясь, пока не прозвенит таймер.
4. Сделайте короткий перерыв (5 минут).
5. После 4-х циклов сделайте длинный перерыв (15-30 минут).
